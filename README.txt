【開き方】
1. このフォルダごとZIPを展開（解凍）してください
2. 「index.html」をダブルクリックするとブラウザで開きます
3. 表紙の「▶ タップして読み聞かせスタート」を押すと、
   音声の読み上げが始まり、ページも自動でめくれます

【操作方法】
・▶ / ❚❚ … 再生 / 一時停止（スペースキーでもOK）
・◀ / ▶▶ … 前のページ / 次のページ（矢印キーでもOK）
・「自動めくり」… オフにすると手動でページをめくれます
・「1x」… 読み上げ速度を変更できます（0.75〜3倍）
・図解や画面写真は、クリックすると大きく表示できます

【注意】
・音声ファイルが同じフォルダの assets 内に入っています。
  index.html だけを移動すると音が出なくなるので、
  フォルダごと移動してください
・スマホでも開けますが、パソコンでの閲覧がおすすめです
